# 版管理・影響特定の動作例（模擬の改訂）

Work の実データ（30事実・4草案）に、**筑波大学 知識情報・図書館学類の募集人員 5名→6名**という**模擬の改訂**を入れて、`src.versioning` の CLI を実際に実行した結果。**公式PDFが実際に改訂されたわけではない。**

- 新版は、根拠レコードの引用文からページを組み立てた最小の版（PDF全文は使っていない）。
- `simulated_change.diff.json`：旧版と新版の差分（変更行の数量が `persons:5` → `persons:6`）。
- `simulated_change.impact.json`：影響を受ける事実・記事。

## 結果

| 対象 | 判定 | 理由 |
|---|---|---|
| 事実 `EV-T27-01-49cb4d`（募集人員） | `value_change` | 引用文の数字だけが 5→6 |
| 同じ p.5 に引用文がある4事実（方針・第1次選考・面接・面接範囲） | `page_changed` | 引用文は残るが、同じページの数字が変わった（旧版を渡したので判定できる） |
| 上記以外の25事実（筑波の別ページ、慶應の全事実） | `intact` | 変更なし |
| 筑波の概要記事 | `republish_required` | 募集人員の事実を引用している |
| 筑波の面接記事 | `review` | 募集人員は引用しないが、p.5 の4事実を引用している |
| 慶應の記事2本 | `ok` | 影響なし |

`impact` は、旧版を渡さない場合は引用文そのものの変化だけを見る（`page_changed` は出ない）。
