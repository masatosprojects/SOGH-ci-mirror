### Work の報告との食い違い・注意点

- 旧27事実の分類「20一致＋7条件補足」は、私の判定（値の増減）とは一致しない（私の判定では17件が新事実で値が増えている）。分類の定義の違いで、矛盾ではない。
- Work の説明「DB QAの警告1件は、同じ原文位置を複数事実が共有する関係」は**不正確**。実際の警告は、私のQAツールの**誤検出**だった（複合主キーの関連テーブル `fact_evidence` を重複と誤判定）。ツールを修正し、警告は消えた。旧DBの `fact_evidence` 27件は**引用文（excerpt）が全件NULL**で、位置情報（locator）しか持たない。新v0.3では原文引用付きの根拠に置き換わっている。
- 新しい根拠の引用範囲（`proofs`）が、記事の主張より狭い箇所がある（例: 慶應の出願資格は条件2のみを引用しているが、記事は「学歴等の条件」にも触れる。PDF本文では支持されている）。値の誤りではないが、引用の粒度として記録。
