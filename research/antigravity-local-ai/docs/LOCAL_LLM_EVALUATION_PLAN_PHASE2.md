## 2. 実機推論に向けた安全前提条件（Pre-flight Safety Gates）

実モデル推論を開始する前に、以下の **5大ゲート** をすべてクリアする必要があります。

1. **Gate 1: 温度センサーの可視化**:
   - `HWiNFO64.exe` が「Shared Memory Support」有効で起動しており、CPUおよびGPU温度が実測値として取得できること。
   - 測定温度が **75.0℃以下（GREEN）** であること。`UNKNOWN` の状態では推論開始禁止。
2. **Gate 2: メモリ余裕の確保**:
   - 実行対象モデルのサイズ ＋ 500MB以上の空き物理RAMが存在すること。
   - 4Bモデル（約2.5GB）を実行する場合、不要プロセスの終了により空きRAMを3.2GB以上確保すること。
3. **Gate 3: 有人監視（Human Supervision）の必須化**:
   - 無人のバックグラウンド推論や夜間巡回は行わず、ユーザー様が端末前に待機している状態でのみ短時間実行する。
4. **Gate 4: 1推論あたりの実行時間上限（Hard Timeout）**:
   - 1プロンプトあたりの推論時間は最大30秒に制限し、超過時は自動でサブプロセスを終了（Terminate）する。
5. **Gate 5: 異常時の即時停止機構**:
   - メモリ使用率92%超過、または温度85℃超過で即時停止（Emergency Abort）する。

## 4. 架空評価データセットの構成（`sogh_admission_eval_set_v1.json`）

SOGHの実務要件（自社Webでの根拠付き入試情報提供・AI模擬面接）に基づき、以下の6問からなる評価セットを準備完了：

1. **TC-EXTRACT-001 (情報抽出)**:
   - 筑波大学工学システム学類AC入試の要項抜粋から、大学・学類・年度・方式・募集人員（10名）・提出方式を正確に構造化JSONとして抽出できるか。
2. **TC-SEPARATE-002 (年度・方式の厳格分離)**:
   - 2026年度実績（10名）と2027年度計画（12名）、一般選抜（50名）が混在する文面から、2027年度AC入試の定員を混同せずに回答できるか。
3. **TC-WITHHOLD-003 (根拠不足時の保留 - STR-014/STR-036/STR-038)**:
   - 「詳細は6月公表」とある未定情報に対し、前年度の数値を捏造（ハルシネーション）せず、「未定・保留」と回答できるか。
4. **TC-PROHIBIT-004 (禁止置換ルール検知)**:
   - 「自己推薦書が廃止された」という誤報・改変言説に対し、公式DBの禁止ルール（prohibited substitution）を照合して即座に不正を検知・棄却できるか。
5. **TC-DIALOGUE-005 (模擬面接・個人情報保護)**:
   - 受験生の回答文に含まれる電話番号等の個人情報をマスキングし、活動実績に即した本番に近い深掘り質問を生成できるか。
6. **TC-MULTICOLLEGE-006 (複数学類の定員分離)**:
   - 工学システム学類（10名）、社会工学類（5名）、情報メディア創成学類（5名）の定員が互いに混同（クロスコンタミネーション）しないか。
