# G7：表のセルを一次根拠にする契約案と、1 方式分の E2E の入出力（Claude、2026-11-02）

**設計案（未合意・未実装）。** 新しい `fact_key`・運用スキーマ・登録はユーザー・Work・Claude の合意の後。M1 の 8 ゲートの定義は変更しない。g7（新しい様式の大学・方式の実データ検証）は、この受け入れ条件がそろってから判断する。
背景：Work の PR #103（京都大学理学部 2027 年度特色入試の座標設定型 probe）と、私の独立再現（実 PDF〔SHA 固定・読み取りのみ〕で、概要表の罫線と文字から**独立に**導いた 5 行・枠・人数・総定員が Work の候補と一致）。

## 1. 根拠の構成（一次＝表のセル、二次＝別資料の本文）
**一次の根拠 `table_cell`**（行ごとに 3 セル＋任意の合計セル）
| 項目 | 内容 |
|---|---|
| `source_sha256`・`page`・`page_size` | 資料のバイトと頁。頁サイズが違えば拒否 |
| `extractor_id` | 例：`pymupdf-page-get_text("words")/<版>`。位置・矩形の意味は抽出器で決まる |
| `profile_id`・`profile_sha256` | 矩形を決めたレビュー済みのプロファイルの識別子と SHA（人がレビューし固定したもの） |
| `role` | `label`（入試区分）／`pool`（募集枠）／`count`（人数）／`total`（学部総定員）／`general`（一般選抜の人数） |
| `rect` | PDF point・左上原点の矩形（セル全体が矩形に収まる語だけを採る） |
| `cell_text_sha256` | セルの正規化テキストの SHA（本文はリポジトリに載せない） |
| `row_id` | 同じプロファイルの同じ行のラベル・枠・人数を束ねる ID |

**行の束縛の条件（コードで強制する。PR #103 の K-1 修正で一部入った）**：①枠の矩形の縦範囲が、その行のラベルと人数の矩形を**包含**する（結合セルは複数行にまたがる）、②ラベルと人数の縦範囲が**重なる**、③各セルの語は矩形に**収まる**（境界で切れた語は拒否）、④空・複数の数字・曖昧なセルは拒否（0 を既定にしない）、⑤フラットなテキストの出現順は行の束縛に**使わない**。
**二次の根拠 `guide_span`**：別資料（募集要項）の該当区間——頁全文の正規化テキストでの絶対位置（開始・終了）、区間の SHA、`(ラベル)N人` を含む引用。既存の「値が引用に含まれる」ゲートは、この引用で働く。二次根拠は**ラベルと人数の対応だけ**を補強する：実資料では、枠（一般枠／女性募集枠）と総定員（311）・一般選抜（274）は要項の該当区間に**書かれておらず**、概要表だけが根拠。したがって枠・総定員は「単一の資料に基づく」と明示する（二次根拠があるように見せない）。
**値の意味は分けて持つ**：募集枠（一般枠／女性募集枠）、入試区分（特色入試の方式名＝**学科名ではない**）、選抜区分（総合型選抜／一般選抜は別の値）、単位（名）、年度（2027 年 4 月入学者）。「特色入試の一般枠」を「一般選抜」と混同しない。

## 2. 限界の現況（head `a850773` 時点）
- **K-3・K-4 は Work が対応済み**（読み順 `vertical-rtl` の明示、レビュー済みブロック内の矩形へのアンカーの束縛）。独立に確認した（`tests/test_pr103_layout_probe_review.py`）。以下はこの契約案としての要件の記録。

## 2a. 要件（K-3・K-4・その他）
- **K-3 複数列の縦書き**：セル内の語は `(y, x)` 順で並ぶため、2 列の縦書きは順序が崩れる。ラベル一致検査が止める（fail-closed）が、新しい様式では**読む順序をプロファイルで明示**（`reading_order`：`column_rtl`／`column_ltr`／`row`）し、試験で固定する。
- **K-4 年度のアンカー**：`year_anchor` は頁全文の部分文字列。**表のタイトル・見出しの矩形**に束縛する（`year_rect`＋その文字列）。他年度の表が同じ頁にある場合の混入を拒否する負例を置く。
- **K-5（情報）矩形は描かれた罫線に束縛されていない**：独立に導いた罫線（行の境界・枠の境界）と Work の矩形は一致するが、最後の枠の矩形の下端は罫線より 6pt 下（731 と 725）。プロファイルの作成時に、矩形が罫線の区画に収まる検査を加えると、人の目だけに頼らない。
- 回転した頁、図形だけの数字、スキャン・OCR、結合セルの途中で切れた表、別版の SHA は、すべて**拒否**（別のレビュー済みプロファイルが要る）。

## 3. 1 方式分の E2E（Work の次の実装）の入力・出力の契約
**前提**：安全なコピー（使い捨てクローン）だけ。運用DB・原本・監査コピーは読み取りのみ。凍結 0002〜0009 を適用したコピー。**まず 1 区分（例：数理科学入試）だけ**を対象にし、5 区分を「対応済み 5 方式」に加算しない。
- **入力**：①レビュー済みのプロファイル（SHA 固定）、②資料 2 件（概要表・募集要項）の保存バイト（SHA 固定）、③ケース（大学・学部・方式・年度）の定義と対応づけ（要項の記載による。**概要表単独では学部の入学年度の対応は明示される**が、方式の `case` への対応づけは別に根拠を持つ）。
- **出力**（すべて隔離コピー内）：
  1. 原典の登録（`source_documents`・`source_pages`・G06 のメタデータ・検証イベント：`bytes_match`・`stored_file_matches` は pass、`official_site_authenticity`・`content_meaning_checked` は `not_run`／`docs/SOURCE_EVIDENCE_LEVELS.md`）。
  2. 根拠 1 件：値＝人数（整数）・単位・募集枠・入試区分・選抜区分・年度、`proofs`＝一次（`table_cell`）＋二次（`guide_span`）。
  3. 記事：その根拠だけを引用する草案（`publish_allowed=false`、未公開・未有効化）。
  4. QA：既存の export ゲート・記事 QA・引用値ゲートを**変更せず**に実行。全体 QA が不合格なら、その結果を保存して停止（しきい値を変えない）。
- **合格条件（Claude の独立再現）**：①プロファイルの SHA 以外の入力では動かない、②行の取り違え・枠の取り違え・別年度・別版・出現順の入れ替えで拒否、③根拠の値が引用（二次）に含まれる、④他の方式・他の学部の記事・根拠が変化しない、⑤`finalize` を呼ばない／head 不変、⑥人の確認（`content_meaning_checked`）は `not_run` のまま。
- **負例（最低限）**：枠の借用、別行の人数、同じ文字列の別セル、境界にまたがるラベル、複数列の順序、一般選抜と特色の混同、総定員と方式別の混同、年度の混入、頁の回転、スキャン。
