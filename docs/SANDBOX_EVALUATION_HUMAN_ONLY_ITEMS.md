## 2. 今回の欠陥修正
追質問の「同じ言葉を二度尋ねない」判定が、**生の文の範囲と、切り詰めた引用の範囲を比べていた**ため、引用が切り詰められると一致せず、同じ文に何度も追質問していた（上限の 5 件を同じ文で使い切る）。尋ねた**言葉そのもの**で判定するよう修正（`sandbox/interview_sandbox/engine.py`）。ルーブリックの段階の付け方は変更なし。

追加（第 3 期の発見）：途中で終わった練習（時間切れ・本人の終了）でも、5 項目すべてに段階を付けて表示していた。質問されていない分野（例：「学びたいこと」）に依存する項目まで「一部できている」と出ていた。段階の付け方（ルーブリック v1.2）は変えず、**質問されなかった分野を名指しして、依存する項目を参考にしないよう注意する文**を結果に足した。

## 3. 人にしか確認できないこと（未実施。これを機械の試験で代替しない）
1. **追質問が良い質問か**：面接官の目で見て、受験生の回答を深めるか、不自然・誘導的・圧迫的でないか（型の正しさではなく質）。
2. **ルーブリックの妥当性**：段階（例：明瞭さ）が、実際の面接官・指導者の評価と一致するか。複数の評価者の一致度（評価者間信頼性）。
3. **フィードバックの有用性と受け止め**：受験生が理解でき、行動を変えられ、傷つけない文面か。改善例が本人の考えに沿うか（数字や事実を足さないことは機械が確認済みだが、「その人らしさ」は人が見る）。
4. **再挑戦で実際に良くなるか**：機械は「改善した回答が下がらない」ことだけを見る。上達そのものは縦断の評価が要る。
5. **公式情報と AI 素材の区別が読み手に伝わるか**：節を分けて表示していても、読み手が混同しないかは利用者テストが要る。
6. **機微な話題・個人情報の扱い**：氏名・住所は自動で伏せない（限界として表示）。実際の利用で何が入力されるかの観察と、必要な追加対策の判断。
7. **指導者・学校での運用の適合**：先生が使う場面での説明、同意、記録の扱い。
8. **公平性**：話し方・語彙・方言・障害による差が、段階に不当に影響しないか。
9. **ためらい・自信のなさ（「たぶん」「自信はありません」）の評価**：ルーブリックは最初の一文の長さと広い語で「明瞭さ」を見ており、ためらいの表現そのものは段階に影響しない（機械は「間違いと断定しない」「数字を足さない」ことだけを確認）。ためらいを段階にどう反映するか（反映すべきか）は人の判断で、ルーブリックの版を上げる変更になる。
実施にあたっては、同意・匿名化・保存期間の取り決めを先に決める（実データを扱う前の別承認。このリポジトリにはまだ無い）。
