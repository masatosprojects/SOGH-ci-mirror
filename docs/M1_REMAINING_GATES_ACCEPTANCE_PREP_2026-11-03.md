# M1 の未達ゲート（g1・g3・g5）：承認の前に安全に検証できる範囲と、承認が要る操作

**ラベル：整理（`SELF_VALIDATED`）。ゲートの定義・しきい値は変更していない。M1 は 2/8（g4・g8）、NOT ACCEPTED。** ここにある「検証できる」は、運用 DB・監査原本・署名鍵に触れず、使い捨てのコピーで行えることを指す。**承認が要る操作は、ユーザーが選ぶまで実行しない**（運用への適用・F-2 の署名・G-05 の別名の採用・v0.2 の移行を含む）。

|---|---|---|---|
