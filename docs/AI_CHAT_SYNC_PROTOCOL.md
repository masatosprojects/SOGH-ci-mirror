# SOGH｜GitHub原本・短文チャット・2台非同期運用（2026-11-08）

## この規約の出所と適用範囲
- **出所**：2026-11-08 SOGH05における本人の明示的な運用要請。長大な実行プロンプトを通常ChatGPTチャットに全文掲載しない。メインPCとゲーミングPCで同一ChatGPT Webチャットを開いた際の表示同期遅延に作業連携を依存させない。
- **性質**：コミュニケーション・引き継ぎ方法のみ。事業STR、個別技術実装の許可、M1正式受容、製品の安全制限緩和を意味しない。既存の最優先「自律計画・依存隔離」規約を維持する。
- **GitHub原本**：非公開`masatosprojects/SOGH-collab`の`master`。本規約・`docs/COORDINATION.md`、成果ハブIssue #199、監査Issue #214、各自の担当PR/Issueを参照する。GitHubに秘密・個人情報・原典全文を記録しない。

## チャットでの出し方：最優先
1. 通常ChatGPT（指令塔）は**長い実行プロンプトの全文を原則としてチャットへ掲載しない**。ユーザーが明示的に全文表示を要求した場合のみ例外とする。
2. 各AIが読むべき詳細は、すでにGitHubにある本人RESULT・担当PR・#199を参照する。必要な追加の運用文書はGitHubに置き、チャット側では**担当AI、要点1〜3行、リンク、受信/未受信状態、ユーザー操作の要否**だけ伝える。同じ内容を両端末のチャットへ大量にコピーペーストしない。
3. 同じChatGPT Webチャットを複数PCで同時に開いても、表示のリアルタイム同期は保証されない。**チャット画面表示・リロード完了を作業進行の同期条件にしない**。原本と事後確認はGitHubの固定HEAD・本人ACK・RESULTで行う。
4. 指令塔はGitHubを読む/監査する役。従来どおり新しい`CMD-*` Issueや各AI向け長文の逐次指令を増やさず、AI各自の安全な自己計画を優先する。ユーザーが個別に新たな実行指示を明示した場合は、担当の既存Issue/PRや適切な文書に**必要最小限の差分**だけ記録する。重複した新規Issue/指示を作らない。

## 各AIが能動的に発見・読解する手順
- セッションの**開始・節目・終了前**に最新`master`と本規約・`docs/COORDINATION.md`、Issue #199の**最新コメント**（本文だけに依存しない）、#214、自担当PR/Issueの最新HEAD、承認済みSTR・安全制約を取得する。
- 最新の本人RESULTにある`READY_INDEPENDENT_next_1(max_2)`と`WAITING_DEPENDENCY`を照合し、**既に許可された担当・低費用・安全な独立タスクのみ**自律的に選択する。新しい修正HEAD・受容・権限が必要な作業は対応する条件が満たされるまで止める。
- 未確認の重要差分を読んだ場合、担当AIは`ACK`として参照したGitHub URL/コメントID・`master` SHA・対象固定HEAD・理解した差分・本人直接指示との整合・次の小タスク/依存を既存Issue/PRまたは#199に残す。完了後は`RESULT`としてPASS/FAIL/NOT_RUN、自己試験/独立QA/正式受容の区別、次の最大2タスクを記録する。
- GitHubへの掲載は**プッシュ配信・チャット起動・本人ACKを意味しない**。本人が各AIの現在のセッションに短文で「GitHubの最新原本を読んで」と伝えることが必要なケースはあり得る。その際も長文プロンプトをチャットへ複製しない。

## 出所と権限の分離（必須）
- `USER_DIRECT`：そのAIが本人から直接受け取った明示指示、または本人の承認が正確に追跡可能な正式運用方針。**今回の「GitHub原本・短文チャット」だけは本人が明示要請した運用ルール**。
- `AI_PROPOSAL`：指令塔/実行AIの提案・計画・GitHubコメント。**AIが記載しただけでは本人の直接指示・許可には昇格しない**。本人の意思決定を捏造しない。
- `APPROVED_STR`：正式にユーザー承認されmasterに統合した事業判断。**一般的な技術実装・本番変更・課金を許可するものではない**。
- 直接ユーザーチャット・GitHub記録に矛盾/不明点があれば、各AIは`CONFLICT_REQUIRES_USER`または`UNKNOWN`で止め、指示の出所を明示する。
- 本番DB・実受験生データ・監視/通知の本稼働・実モデル推論・追加課金・技術PRマージ・正式受容・本人署名代理は**個別の明示許可がない限り禁止**。

- **メインPC**：Claude Code実行環境とChatGPT Work実行環境。Workは別途本人解除まで原則`PAUSED_FOR_QUOTA`。
- **ゲーミングPC**：Google Antigravity実行環境（独立QA）と、将来別途許可後のローカルLLM実験候補。Claude Code・WorkはこのPCで実行していない。AntigravityとローカルLLMのRAM・CPU競合制約を維持。
