## 2. 題名と表の結合方法の比較
| 案 | 長所 | 短所・負例への強さ | 採否 |
|---|---|---|---|
| 固定距離（80pt／160pt） | 単純 | 距離は意味ではない。160pt にしても、題名を移動した改ざん、間に別の表がある場合を見分けない。**実資料で 152pt**＝閾値の恣意的な引き上げになる | **不採用**（理由：単純な数値の拡張を避ける要請） |
| レビュー済みの**題名→表のスコープ矩形**（profile に明示） | 正しい関係をそのまま表現。profile の SHA で固定。ポスター型・複数ブロックの資料にも使える | スコープを広げれば年度の混入が見えるが、広げ方は人のレビューに依存 | **採用（主）** |
| 表ブロック ID | 明示的 | 実質は上と同じ（ID が矩形を指す） | 上に含める |
| 包含関係（題名が表のブロック内） | 自然 | ポスター型では題名が別ブロック | 補助（スコープ内に題名・表がある） |
| 隣接する複数の表との関係 | 別表の混入を直接拒否 | 描画の連結成分の数を数えるので、図形以外の表は見えない | **採用（補助）**：スコープ内の**描かれた表の数が profile の宣言と一致** |
| profile SHA・原典 SHA の固定 | 改ざん・差し替えを拒否 | 意味は保証しない | **採用（前提）** |

## 3. 契約 v1.1（`table-cell-evidence-v1.1-candidate`）
1. **title scope**：profile に `title_scope`（頁内の矩形）と `expected_table_clusters`（スコープ内の描かれた表の数）を明記し、レビューして SHA で固定する。距離の上限は持たない。
2. **年度アンカー**：`year_anchor` は `{text, rect}`。矩形は title scope の内側で、**表より上**（`anchor.y1 ≤ table.y0`）。文字列は、その矩形に頁が実際に持つ文字と一致（移動・捏造の拒否。正規化＝NFKC・空白除去）し、入学年度を名乗る（令和 N 年は N+2018 に換算）。
3. **表はスコープの内側、かつ描かれた表の内側**：`table_rect ⊂ title_scope`、`table_rect ⊂ 描かれた表の外接（±3pt）`（表領域だけを拡大した偽装を拒否）。
4. **年度の一致**：スコープ内のすべての年度の文字列（西暦・令和）が `admission_year` と一致する。別年度が 1 つでもあれば `E-YEARCONFLICT`。年度の文字列が 1 つも無ければ失敗。
5. **表の数**：スコープ内の描かれた表の数が宣言と一致（隣接する別表の混入を拒否）。
6. **固定**：`(profile_sha256 → source_sha256, reading_order)` のレビュー済みの対応表に一致しなければ `E-PIN`／`E-ORDER`。ページ事実を読んだバイトの SHA が原典と違えば `E-PIN`。
7. **ページ事実が無い場合は警告（`E-FACTS`）**：新しい様式では、独立のページ事実（本書の抽出器など）が必須。
8. **K-5（罫線）**：§5。

## 6. 区分別募集人員の `fact_key` 案（正式登録は合意後）
既存の `quota`（`src/verify/data/fact_keys.json`）の範囲は department_and_method／faculty_annual_AO_aggregate／target_admission_cycle で、**募集単位（入試区分）ごとの値ではない**。流用しない。仮称：**`admission_unit_quota`**（Work の `admission_category_quota`、Claude の草案 `admission_quota_by_category` は同じ意味の別名の仮称。正式名は合意で 1 つに）。
| 項目 | 定義 |
|---|---|
| 値 | `count`（正の整数）、`unit`（`名`） |
| 募集単位（admission unit） | 入試区分の名称（例：数理科学入試）。**学科名ではない**。値の識別の一部 |
| 募集枠（pool） | 一般枠／女性募集枠など。同じ募集単位に複数の枠があり得るので識別の一部 |
| 選抜方式（selection） | 特色入試／総合型選抜／学校推薦型／一般選抜など。**資料の文言から**得る（推測しない）。「特色入試の一般枠」を「一般選抜」と混同しない |
| 入学年度（admission year） | 例：2027 年 4 月入学者（題名の矩形から） |
| 実施年度（exam year） | 例：令和8年度に実施する試験。入学年度と別に持つ（取り違えない）。資料に明示が無ければ `null`＋理由（推測しない） |
| 大学・学部・方式（case） | 既存の case の識別（`university／faculty／admission_method`）。学部総定員と区別 |
| 必須根拠 | 一次＝`table_cell`（表のセル、行ごと）、二次＝`guide_span`（要項の該当区間。ラベルと人数の対応だけ）。**枠・総定員は要項に書かれていなければ、概要表だけが根拠と明記**（二次があるように見せない）。`profile_sha256`・`extractor_id` を必須 |
| 同一キーの識別規則 | `(case, fact_key, admission_unit, pool, selection, admission_year)`。同じ組が別の値で 2 件あれば競合として登録を止める（`G-05` の別名と同じ扱い）。募集単位の名称の揺れは別名表で（推測で統合しない） |
| 区別 | 学部総定員（311）・一般選抜（274）・特色の合計（37）は**別の値**（`fact_key` を分けるか、`aggregate_kind` で区別。合計は行の和と一致させる検査を持つ：37＋274＝311） |
| 年度の整合 | 題名の年度、行の年度、`admission_year` が一致（`E-YEAR`） |
登録の条件：ユーザー・Work・Claude の合意、レジストリの必須項目（定義・単位・粒度・必須根拠・値の型・年度の扱い）。合意の前は検査が `E-FACTKEY` で止める。
