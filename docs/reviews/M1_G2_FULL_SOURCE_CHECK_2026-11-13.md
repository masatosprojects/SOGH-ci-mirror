## 方法
- 対象：実 v06 の固定コピー（SHA-256 `a8e48b5b…9578`。検査の前後で一致＝不変）。`source_documents` の 4 件（筑波 AC 募集要項 `49cb4d7d`、慶應 `91dad17f`、新潟大 `2d1ee89f`、筑波 一般 `e1137e2a`）。
- 各原典：Work の作業領域にある**元の PDF**（読み取りのみ。コピーを作業用フォルダに置いて検査）。ファイルの SHA-256 が DB の `sha256` と一致することを確認。
- ページ照合：DB の `source_pages`（合計 169 ページ）を、元の PDF から **2 種類の抽出器（PyMuPDF と pypdf）**で抽出した本文と、空白を除いて比較。`text_sha256` の再計算も確認。
- 根拠照合：`facts` 46 件の `record_json` の `proofs`（引用）57 箇所が、元の PDF の**該当ページ**の本文に、そのまま（空白を除いて）あるか。

- **限界：**①作者＝Claude の SELF_TEST（独立再計算は Antigravity に同じ 4 PDF を渡して別の抽出器で行う必要がある）。②原典が PDF 以外（HTML の FAQ など）の根拠は、この確認の対象外（FAQ の保存 HTML は別に独立QA済み＝Cycle 07）。③『原典が現在の公式サイトと同じか』（原典の更新）は見ていない（新規取得はしない）。④各引用が事実の値を**正しく**表すかの意味の確認ではなく、引用が原典に存在することの確認。
