## 根拠契約の案（Work の依頼「bbox と文字位置を組み合わせる根拠契約」）
合意前に私は実装しない。案：
1. **一次の根拠＝表のセル**。`proof_kind = "table_cell"`：資料の SHA、頁、頁サイズ、**抽出器の ID とプロファイルの SHA**、役割（`label`／`pool`／`count`／`total`）、矩形（PDF point・左上原点）、セルの正規化テキストの SHA。数字は、**同じプロファイルの同じ行**のラベル・枠・人数セルがそろったときだけ値になる（行の束縛は矩形で行い、フラットなテキストの出現順は使わない）。
2. **二次の根拠＝別資料の本文の引用**：要項側の該当区間（`(ラベル)N人` を含む）を、ページ全文の絶対位置・区間の SHA・引用文として保持。既存の「値が引用に含まれる」ゲートはこの引用で働き、セルとガイドが一致することを相互に確認する。
3. **値の意味は分けて持つ**：募集枠（一般枠／女性募集枠）、入試区分（特色入試の方式名）、選抜区分（一般選抜との別）、単位。**入試区分を学科名にしない**。
4. 新しい `fact_key`（例：区分ごとの募集人員）と必須項目はレジストリの変更なので、Work・私・必要ならユーザーの合意の後に。既存 QA は変更しない。
